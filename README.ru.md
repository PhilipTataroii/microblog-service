## О проекте

MicroBlog — RESTful-приложение для микроблогинга, разработанное в качестве итогового проекта программы профессионального обучения Python Advanced.

Приложение позволяет пользователям создавать и удалять публикации, загружать изображения, ставить лайки, подписываться на других пользователей и просматривать персонализированную ленту публикаций.

Проект демонстрирует практические навыки backend-разработки, проектирования REST API, управления базами данных, контейнеризации приложений и автоматизированного тестирования.

## Возможности проекта

- Создание и удаление публикаций
- Загрузка изображений и прикрепление их к публикациям
- Добавление и удаление лайков
- Подписка и отписка от пользователей
- Просмотр профилей пользователей
- Просмотр ленты публикаций
- Сортировка публикаций по популярности
- Авторизация пользователей через HTTP-заголовок `api-key`
- Интерактивная документация API с использованием Swagger
- Запуск приложения через Docker Compose

## Используемые технологии

- **Backend:** Python, Flask
- **База данных:** PostgreSQL, SQLAlchemy
- **Миграции базы данных:** Flask-Migrate, Alembic
- **Документация API:** Flasgger, Swagger
- **Тестирование:** Pytest
- **Проверка качества кода:** Flake8
- **Контейнеризация:** Docker, Docker Compose

## Установка и запуск

### Требования

Для запуска проекта необходимо установить Docker и Docker Compose.

### Установка и развёртывание

Клонировать репозиторий:

```bash
git clone https://github.com/PhilipTataroii/microblog-service.git
cd microblog-service
```

Собрать и запустить приложение:

```bash
docker compose up -d --build
```

Проверить состояние контейнеров:

```bash
docker compose ps
```

После запуска приложение будет доступно по адресу:

`http://127.0.0.1:5000/`

Остановить приложение:

```bash
docker compose down
```

## База данных

В проекте используется реляционная база данных PostgreSQL.

При запуске через Docker Compose PostgreSQL работает в отдельном контейнере.

Миграции базы данных автоматически применяются перед запуском Flask-приложения с помощью команды:

```bash
flask db upgrade
```

## Авторизация

Для идентификации пользователей используется HTTP-заголовок `api-key`.

Пример:

```http
api-key: test
```

Пользователь с соответствующим ключом должен существовать в базе данных.

## Основные REST API-маршруты

| Метод | Маршрут | Описание |
|---|---|---|
| GET | `/api/users/me` | Получение текущего пользователя |
| GET | `/api/users/<user_id>` | Получение пользователя по ID |
| GET | `/api/tweets` | Получение ленты публикаций |
| POST | `/api/tweets` | Создание публикации |
| DELETE | `/api/tweets/<tweet_id>` | Удаление публикации |
| POST | `/api/medias` | Загрузка изображения |
| POST | `/api/tweets/<tweet_id>/likes` | Добавление лайка |
| DELETE | `/api/tweets/<tweet_id>/likes` | Удаление лайка |
| POST | `/api/users/<user_id>/follow` | Подписка на пользователя |
| DELETE | `/api/users/<user_id>/follow` | Отписка от пользователя |

## Документация Swagger API

Интерактивная документация API доступна по адресу:
